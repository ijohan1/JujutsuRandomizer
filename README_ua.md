# Jujutsu Randomizer: створи власного мага.

# швидке ознайомлення:
Цей застосунок є .json генератором даних, що базується на манзі Jujutsu Kaisen від Gege Akutami. Проєкт було створено для можливості цікавіше експериментувати з генерацією випадкових даних для моїх особистих тренувань з аналізу даних.


## переваги:
- .json формат даних
- великий обсяг японських імен та прізвищ для створення персонажів
- всі прокляті техніки з манґи
- простота використання
- загальний шаблон коду, який можна використовувати для будь-яких інших схожих завдань (генерація персонажів/сеттингу для DND, написання історій тощо)


# вимоги:
- python v3.14.4 або новіший
- ОС на базі Linux (опціонально, оскільки може запуститися на Windows, але найлегше запустити саме таким чином)


# встановлення:
клонуйте цей репозиторій з допомогою git:
```git clone https://github.com/ijohan1/JujutsuRandomizer```


# використання: 
1) запустіть файл main.py вашим системним python
2) програма автоматично створить та оновлюватиме папку data з файлом students.json всередині, де і будуть знаходитися згенеровані персонажі
3) відкрийте students.json, аби поглянути, що було створено
4) готово! ви можете створювати персонажів, використовуючи цей генератор, тренувати використання інструментів для аналізу даних, або ж просто посміятися з того, що нагенерувалося.
